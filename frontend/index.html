Analisador Léxico e Sintático

Software educacional de compiladores — subconjunto de Python (Etapa 4: parser e AST)

1. Código-fonte

O que este analisador aceita?

Atribuições (x = 10), expressões aritméticas (+ - * /, parênteses), comparações (== != < > <= >=), if/else, while, def com parâmetros e return, chamadas de função (print(x)), números inteiros e reais, textos entre aspas, True e False e comentários com #.

Ainda não suportado: for, elif, and/or/not, listas, dicionários, classes, comparações encadeadas (a < b < c), comandos na mesma linha do : e quebra de linha dentro de parênteses. Use espaços para indentar (4 por nível).

  • Sintática: aguardando

3. Tokens (análise léxica)

O que é a análise léxica?

O scanner lê o texto caractere por caractere e o agrupa em tokens: cada token tem uma categoria (tipo), o trecho de texto (lexema) e a posição (linha e coluna). Espaços e comentários são descartados.

O scanner testa as categorias numa ordem fixa e escolhe a primeira que casa no ponto atual do texto. Por isso if vira palavra reservada, mas iffy vira identificador, e >= é um único operador, não > seguido de =. Quando nenhuma categoria casa, o trecho vira um erro léxico; o scanner registra o erro e continua lendo, para mostrar todos os erros de uma vez.

    4. Árvore sintática abstrata (AST)
    
      
    
        O que é a análise sintática e a AST?
        
    O parser verifica se a sequência de tokens segue a gramática da linguagem e monta a AST:
        uma árvore em que cada nó é uma construção do programa (atribuição, operação, if...). A precedência aparece na forma
        da árvore: em 1 + 2 * 3, a multiplicação fica mais funda porque é calculada antes. Parênteses guiam a
        montagem da árvore, mas não viram nós.
    
        
    Clique em um nó para destacar o token correspondente e a posição no código.
